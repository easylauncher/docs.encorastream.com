# Encora Stream Documentation

Official documentation for the Encora Stream live streaming platform.

## About

Encora Stream is a comprehensive white-labeled live streaming solution powered by vLive technology. This documentation site provides complete guides for deploying and managing the platform.

## Documentation Structure

- **Input Streams**: Configure video sources from encoders
- **Transcoders**: Set up adaptive bitrate transcoding
- **Packagers**: Configure HLS, DASH, and AES packaging
- **Origin Servers**: Deploy content delivery infrastructure
- **Best Practices**: Guidelines for optimal deployment and operations
- **Troubleshooting**: Solutions for common issues

## Local Development

This site is built with Jekyll using the Just the Docs theme.

### Prerequisites

- Ruby 2.7 or higher
- Bundler
- Jekyll

### Running Locally

```bash
bundle install
bundle exec jekyll serve
```

Visit http://localhost:4000 to view the documentation.
